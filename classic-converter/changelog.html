Explorer Converter Guide Changelog

Changelog

Updates apply to new conversions. Existing Classic stories and previously created drafts are not changed.

1.1.0 · August 28, 2026

Added

  • Map Series output choice: a Collection, or a Story with one sidecar and navigation.
  • Sidecar narrative panels retain supported rich content from each visible Map Series information panel, including text, links, lists, images and embeds.
  • This public changelog, linked from the app footer and included in standalone downloads.

Improved

  • Map Series web maps now become native Collection maps instead of Map Viewer embeds.
  • Per-entry map extent, center/scale, layer visibility and supported popup settings are carried into the converted map configuration.
  • Collection entries retain plain-text summaries. Choose Sidecar when the information panel needs to remain alongside the map.

Fixed

  • Fixed a shared map-configuration issue that could turn hidden layers back on after combining Classic visibility overrides with the source web map.

Review before publishing: source maps are referenced, not copied or modified. Collections retain hidden entries; Sidecar omits them. Unsupported Classic interactions and media may need manual adjustment. Read the Map Series conversion recipe.

1.0.2 · August 28, 2026

  • Public Classic stories remain viewable, but conversion requires ownership or readable content within the signed-in user’s ArcGIS organization.
  • Added access checks to gallery selection, bulk conversion and the worker, including a fresh ownership check before creating items.
  • Blocked anonymous conversion and added explanations for view-only items.

1.0.1 · August 14, 2026

  • Made the OAuth callback path configurable for static hosting, including S3 and CloudFront deployments under a path prefix.
  • The default callback is ./arcgis-oauth-callback.html.
  • Added version and last-updated information to the footer.

This is a free, community-built project—not an official Esri product. These tools are not covered by Esri Technical Support. Use them at your own risk. It does not delete or modify any existing stories.
